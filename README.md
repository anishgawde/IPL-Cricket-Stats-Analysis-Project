# IPL Cricket Stats Analysis 🏏

An IPL Cricket Stats Analysis project developed using Python to analyze match and player performance data from the Indian Premier League (IPL). The project focuses on data cleaning, preprocessing, exploratory data analysis (EDA), and visualization to uncover insights and trends in cricket statistics.

## 🚀 Features

* Match Performance Analysis
* Player Statistics Analysis
* Team Performance Comparison
* Top Run Scorers Identification
* Highest Wicket Takers Analysis
* Exploratory Data Analysis (EDA)
* Data Cleaning & Preprocessing
* Statistical Data Visualization

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib

## 📂 Project Highlights

* Processed and cleaned IPL datasets for analysis
* Analyzed batting and bowling performances
* Visualized team and player statistics
* Identified trends in match outcomes and player consistency
* Generated insights using graphical representations

## 📊 Analysis Performed

* 🏏 Top Run Scorers
* 🎯 Highest Wicket Takers
* 📈 Team Win Analysis
* 📅 Season-wise Performance Trends
* 🔥 Most Consistent Players
* 🏟️ Venue-based Match Insights
